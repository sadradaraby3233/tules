One button. It reads the public node sources, dials only what a browser is actually able to reach - and only the country you picked in Preferences, if you picked one - handshakes each node through the internet you are on right now, and lists only the ones that answer, fastest first. Tap a row or press Enter to copy its configuration into your VPN app.

Tests nodes with about 128 connections at once, the way the v2rayNG app does it, and stops early once it has enough working ones.

Working configurations, sorted by ping

Use the up and down arrow keys to move between configurations. Press Enter to copy the selected configuration. Each row states the ping in milliseconds, then the country, the node name and address, and whether the traffic to it is encrypted.

    All countries lists everything the sources publish. Smart select screens a spread of them from your own line and keeps the countries that answer closest to you. A named country still reads every source, but dials only the nodes that belong to it (and any that name no country), which is what makes the scan fast; it also keeps the list honest about where each node is.

    Saved on this device only, and used the next time you press the button.
